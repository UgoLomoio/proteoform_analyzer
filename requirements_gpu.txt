# ============================================================================
# Proteoform Analyzer -- Hugging Face Spaces (ZeroGPU) requirements
# ----------------------------------------------------------------------------
# This is the requirements file Hugging Face Spaces installs at build time
# (it lives at the repo root next to app.py). It is intentionally LEANER than
# the package's own proteoform_analyzer/requirements.txt: it installs only what
# is needed for the Space to (a) import app.py and build the Gradio UI, and
# (b) run the in-process, ZeroGPU-accelerated steps -- ESM2 sequence embedding,
# the ESM2 zero-shot ddG scorer, UMAP, protein-contact-network analysis, and all
# visualisations / tables.
#
# Heavy optional back-ends are DELIBERATELY OMITTED so the Space builds quickly
# and reliably. They pull large / hard-to-build native wheels and, on ZeroGPU,
# either need external binaries or an API key. Each degrades cleanly at runtime
# with an actionable message (see DEPLOY_HF_ZEROGPU.md > "What runs on ZeroGPU"):
#   * openmm / simtk / mdtraj  -> Molecular Dynamics tab
#   * meeko (+ the `vina` binary)     -> AutoDock Vina docking
#   * ptmpsi                          -> PTM / proteoform side-chain grafting
#   * boltz-api / local boltz binary  -> Boltz-2 folding & docking (set the
#                                        BOLTZ_API_KEY Space secret to enable)
#   * torch-scatter / dgl / e3nn      -> DiffSBDD / GNN ligand design
#   * a local RFAntibody checkout     -> antibody design
# To enable any of them, add the corresponding package here (and, for native
# tools, install them via packages.txt or a custom Dockerfile).
# ============================================================================
